# Слепок — лендинг гончарной студии

Учебный проект UX/UI-дизайнера Александры Зянчуриной: студия, адрес и контакты вымышлены.
Макет — Figma, вёрстка — HTML/CSS/JS без сборки, публикуется через GitHub Pages.

- `index.html`, `style.css`, `script.js` — весь сайт.
- `img/` — картинки, сжатые в WebP, и заголовки в SVG (выгружены из Figma в кривых).
- Десктоп свёрстан на холсте 1440, телефон — 375; страница масштабируется под ширину окна.
